# NACHLAS Attendance v4 — Vercel + Supabase

מערכת נוכחות לנחל״ס, מותאמת לפריסה חינמית/זולה ללא Collector.

## סטאק
- Frontend: HTML/CSS/JS קיים בפרויקט
- Backend: Express שרץ כ-Vercel Function
- Database: Supabase PostgreSQL דרך Transaction Pooler
- Auth: משתמשי האפליקציה נשמרים במסד; cookie מוצפן ב-JWT
- Yemot: חיבור מוכן בצד השרת, כרגע במצב Pending API

## מה קיים
Dashboard, LIVE placeholder, תלמידים, ייבוא Excel/CSV, שיעורים ושלוחות, חישוב נוכחות ואיחורים, דוחות, משתמשים/הרשאות, Audit Log, וחיבור מוכן ל-Yemot.
